# Code of Conduct / Кодекс поведения

[English](#english) · [Русский](#русский)

## English

We welcome respectful, technical collaboration regardless of experience, background or identity. This code applies to repository issues, discussions, PRs, reviews, and related project-maintained communication channels.

**Expected:** assume good intent, discuss ideas rather than personal attributes, give actionable reviews, credit other people's work, respect confidentiality and ownership, and accept reasonable moderator decisions.

**Not acceptable:** harassment or discrimination, insults or threats, sexualized attention, doxxing, posting private credentials or user data, sustained disruption, spam, or retaliating against reporters.

Maintainers may edit/remove violating content, restrict participation, close threads or ban accounts proportionately to severity and repetition, subject to GitHub's platform controls. For abusive platform behavior, use GitHub's **Report content** controls. To request a private maintainer contact for a sensitive conduct concern, open a **neutral, non-sensitive** request in an issue; do not disclose identities, private allegations, or evidence in that public request. A dedicated confidential conduct-report channel is not currently published. Do not promise confidentiality on GitHub issues.

Maintainers should acknowledge concerns when feasible, gather context without publicly exposing affected individuals, avoid conflicts of interest in moderation, and explain decisions to relevant participants when doing so is safe. No fixed response-time SLA is offered.

## Русский

Мы поддерживаем уважительное техническое общение независимо от опыта, происхождения и личных особенностей. Кодекс распространяется на Issues, PR, ревью, обсуждения и другие поддерживаемые проектом каналы.

**Ожидается:** конструктивная критика решений, а не личности; уважение чужого времени и прав на код; конфиденциальность, корректная атрибуция, готовность обсуждать замечания.

**Запрещены:** травля, дискриминация, угрозы, оскорбления, доксинг, публикация приватных данных/секретов, спам, систематический срыв обсуждений и преследование за сообщения о нарушениях.

Модераторы вправе удалять сообщения, ограничивать участие, закрывать обсуждения и блокировать нарушителей соразмерно ситуации в рамках возможностей GitHub. Для жалоб на действия пользователя используйте функцию GitHub **Report content**. Для конфиденциальной жалобы запросите закрытый контакт у мейнтейнера без описания инцидента и персональных данных в публичном Issue. Выделенного закрытого канала пока нет; публичные Issues не конфиденциальны.

Мейнтейнеры по возможности изучают обстоятельства, соблюдают конфиденциальность и избегают конфликта интересов. Фиксированного SLA по жалобам нет.
