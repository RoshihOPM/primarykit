# Избранное и сохранённые поиски — Issue #65

`apps/favorites` — переносимый модуль, включаемый через `--apps favorites`.
Обязательная зависимость: `listings` (и через него `users`).
Catalog, Tasks, Outbox, Redis и WebSocket **не требуются**.

## Создание независимого проекта

```bash
uv run python scripts/new_project.py ../classifieds-api --name classifieds-api --apps favorites
cd ../classifieds-api
uv run python manage.py makemigrations users listings favorites
uv run python manage.py migrate
```

Сохраняйте миграции **в новом проекте**. Не заменяйте ими историю
существующей клиентской базы данных.

## API

Нужен авторизованный, активный пользователь с подтверждённым email.
Права staff/superuser не позволяют читать чужие избранные объявления.

- `GET /api/v1/favorites/` — пагинированный список видимых закладок с данными Listings.
- `POST /api/v1/favorites/` + `{"listing_id":"UUID"}` — добавить публичное
  объявление от активного продавца (201); повторное добавление вернёт 200.
- `GET /api/v1/favorites/{id}/` — только своя видимая закладка.
- `DELETE /api/v1/favorites/{id}/` — удалить только свою, даже после снятия
  объявления с публикации.
- `GET/POST /api/v1/saved-searches/` — список и создание сохранённого поиска.
- `GET/PATCH/DELETE /api/v1/saved-searches/{id}/` — чтение, изменение и
  удаление строго своего поиска.

Тело создания поиска: `{"name":"Cars","filters":{"category":"cars","min_price":100}}`.
Допустимы только `category` (slug 1–80), `q` (1–80), `location` (1–120),
`min_price` и `max_price` (целые числа 0–10^15 в минорных единицах).
Неизвестные ключи, вложенные условия, bool вместо цены и перевёрнутые диапазоны
запрещены. Максимум **20 поисков на пользователя**.

## Безопасность и масштабирование

DB UNIQUE(owner,listing) предотвращает повторные закладки. Квота сохранённых
поисков проверяется в транзакции с `SELECT FOR UPDATE` на строке пользователя
(PostgreSQL); SQLite не предоставляет тех же гарантий. Только опубликованные
объявления активных и подтвердивших email продавцов доступны для добавления
и чтения. После архивации/продажи закладка временно скрыта, но владелец может
удалить её по известному ID.

DRF локально ограничивает 120 чтений и 60 мутаций в минуту; для нескольких
воркеров нужны shared или edge лимиты. Уведомления по сохранённому поиску
**не отправляются**. Будущая функциональность должна включаться по согласию
пользователя, иметь дедупликацию и использовать Tasks/Outbox только при выборе
этих модулей. Никаких глобальных подписок нет.
