# Зафиксированные профили схемы

Новый клиент фиксирует `catalog`/`inventory` как `standalone` или `tenant` в `primarykit-origin.json`. Offline doctor запрещает незапланированное изменение режима после генерации. Уже существующие клиенты без этого поля работают как раньше. Истории миграций модулей пока принадлежат клиенту; внедрение версионируемых миграций с проверкой PostgreSQL и отдельными графами запланировано в #88. Никогда не меняйте профиль на существующей базе без явной миграции данных.
