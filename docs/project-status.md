## Что пока не подтверждено или не готово

- **CI исходника** успешен для указанного коммита, но это не подтверждение безопасности любого созданного проекта в production.
- **Приватность репозитория:** на момент проверки репозиторий закрыт.
- **GitHub Release:** на момент проверки не создан.
- **Лицензия:** выбрана MIT; добавлена в PR по open-source оформлению, но права распространения необходимо проверить до публикации.
- **История Git:** отсутствие секретов и правовые основания публикации всей истории не проверены.
- **Commerce:** Payments не имеет реального провайдера, Sales не списывает Inventory, Orders не является полноценным серверным pricing engine.
- **Локализация:** основные руководства доступны на RU/EN, а подробные документы модулей в `docs/` остаются на языке оригинала (часть RU, часть EN).

## Следующий этап

Аудит Git-истории и прав на код, выбор лицензии, защита `main`, внешние smoke/security и beta-релиз только после одобрения владельца. Новые бизнес-модули не должны подменять тесты реальных интеграций и проверку сквозных бизнес-сценариев.

Актуальное состояние всегда нужно сверять с веткой `main`, PR и GitHub Actions, а не только с этим датированным документом.
