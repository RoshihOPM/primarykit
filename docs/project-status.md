# Состояние проекта PrimaryKit

**Язык:** Русский · [English](en/project-status.md) · [Документация](README.md)

**Проверено 21 октября 2026 г.:** репозиторий `RoshihOPM/primarykit` уже **публичный**, основная ветка — `main`. В README указана версия исходников `0.1.0`; каталог содержит **37 приложений**: 3 базовых и 34 выбираемых. Это развивающийся конструктор Django/DRF backend-проектов, а не сертифицированная production-платформа.

## Реализовано

Генератор независимых проектов, манифесты и выбор модулей, пресеты, диагностика `doctor`, планирование миграций, осторожное обновление неизменённых файлов и проверка контрактов. Среди модулей есть пользователи, разграничение прав, Storage, Tasks, Outbox, Webhooks, CRM-компоненты и демонстрационные бизнес-модули.

Состав и ограничения см. в [README](../README.md), [каталоге](modules.md) и [описании возможностей](en/features.md). Проекты владеют своими исходниками, миграциями, инфраструктурой и релизами. В частности, Payments не проводит реальные платежи, а Sales не списывает Inventory автоматически.

## Границы релиза

- MIT-лицензия присутствует, но происхождение стороннего кода и права распространения ещё требуют независимого подтверждения.
- Не считать не запустившийся, пропущенный или заблокированный job успешным CI.
- История миграций сгенерированных клиентов принадлежит самим клиентам; автоматического обновления схем продакшен-БД нет.
- Публичный репозиторий не означает официальный релиз или подтверждённую безопасность.
- До beta-релиза необходимы зелёный CI, реально защищённый `main`, завершённый аудит и опубликованные ограничения.

Это датированный снимок; окончательную картину определяют актуальные коммиты, Issues, PR, GitHub Actions и настройки защиты ветки.
