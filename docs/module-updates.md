# Безопасное обновление скопированных модулей

Код, история миграций и эксплуатация остаются под контролем клиентского
проекта. Используйте **доверенную копию PrimaryKit с доступной историей Git**.
Команды обновления запускаются из исходного репозитория, но работают с
отдельным клиентским проектом.

## Проверка без изменений

```bash
python scripts/module_upgrade.py --source . --project ../client-api --json
python scripts/module_upgrade.py --source . --project ../client-api --three-way-plan --json
```

Отчёт классифицирует изменения источника и клиента. План трёхстороннего
слияния дополнительно проверяет исходные Git-объекты и возможность слияния.
Оба режима ничего не изменяют.

## Применение с явным разрешением

`--apply-safe` переносит только неконфликтующие изменения неконтрактных
Python-файлов. При неизвестной истории, удалении файлов или изменении
критичных контрактов операция отклоняется целиком.

`--apply-three-way` уже реализует **ограниченное** трёхстороннее Git-слияние
неконтрактных Python-файлов. Нужны чистая feature-ветка клиента,
неизменённые исходные модули и проверяемые SHA исходной истории.

```bash
git -C ../client-api switch -c chore/primarykit-upgrade
python scripts/module_upgrade.py --source . --project ../client-api --three-way-plan --json
python scripts/module_upgrade.py --source . --project ../client-api --apply-three-way --json
git -C ../client-api diff --check
git -C ../client-api diff
# Затем — ревью, PostgreSQL-тесты, коммит и PR в репозитории клиента.
```

Инструмент подготавливает файлы и обновлённые отпечатки для записи, а при
обычной ошибке записи пытается восстановить предыдущие версии. **При аварийном
завершении процесса полной транзакционности файловой системы нет.**
Инструмент не создаёт миграции, коммиты, PR, не обновляет зависимости и не
деплоит проект. Модели, контракты API, права, миграции и изменения схемы БД
всегда требуют отдельного ревью. Успешный текстовый merge не гарантирует
семантическую совместимость.

Подробнее: [технические ограничения](en/three-way-upgrade-plan.md),
[контракт миграций](bundled-migration-contract.md),
[issue #89](https://github.com/RoshihOPM/primarykit/issues/89).
Совместимость обновлений между официально выпущенными версиями ещё не доказана.
