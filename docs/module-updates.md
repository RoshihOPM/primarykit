# Обновление скопированных модулей

В клиентском проекте код и миграции принадлежат клиенту. Перед обновлением
закоммитьте рабочую копию. Используйте только доверенный исходный каталог.

```bash
python scripts/module_upgrade.py --source . --project ../client-api
python scripts/module_upgrade.py --source . --project ../client-api --apply-safe
```

Без флага команда строит read-only отчёт. `--apply-safe` переносит только
неконфликтующие изменения Python-файлов вне критичных контрактов при условии,
что клиент не модифицировал эти файлы относительно сохранённых хэшей.
При конфликтах, изменениях моделей, миграций, сервисов, разрешений или
манифестов операция полностью отклоняется. После успешного применения
обновляются исходные отпечатки файлов.

**Не реализовано:** трёхстороннее слияние, управление зависимостями, история
версионируемых миграций, автоматическое изменение схемы БД. После обновления
нужны ревью diff и PostgreSQL-тесты. Для восстановления после сбоя используйте Git.
